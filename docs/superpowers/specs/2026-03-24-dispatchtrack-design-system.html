1. Resumen General

DispatchTrack es una plataforma de trazabilidad logística en tiempo real para el área de Despacho de Agrosuper S.A. (3 edificios, 11 andenes). Este documento define el sistema de diseño visual y las decisiones de arquitectura frontend validadas durante el brainstorming.

6.2 Cards KPI

  • Fondo: --bg-surface
  • Borde: 1px solid --bg-elevated
  • Border-radius: 6px
  • Padding: --space-4 (16px)
  • Label: Oswald 11px uppercase, --text-muted
  • Valor: Sono 36px bold, color según significado semántico
  • Tendencia: Sono 12px, coloreado (success/error)

6.3 Tablas

  • Header: --bg-elevated, Oswald 10px uppercase --text-muted
  • Filas: Alternando --bg-surface / --bg-primary
  • Celdas: Sono 12px para datos, Oswald 12px para campos descriptivos
  • Hover: rgba(245,110,15,0.04) + border-left: 2px solid --accent
  • Contenedor: 1px solid --bg-elevated, border-radius: 6px
  • Filtros: Tabs sobre la tabla: activo = accent 12% + borde, inactivo = --bg-elevated

6.4 Inputs

  • Fondo: --bg-elevated
  • Borde reposo: 1px solid --bg-elevated
  • Borde focus: 1px solid --accent + glow rgba(245,110,15,0.15)
  • Borde error: 1px solid --error + glow rgba(212,128,122,0.15)
  • Altura: 40px (default, alineado con botones Medium), 32px (compacto)
  • Padding: --space-2 vertical (8px), --space-4 horizontal (16px)
  • Label: Oswald 11px uppercase, cambia color según estado
  • Texto ayuda: Oswald 11px, --text-muted (hint) o --error (validación)
  • Disabled: 50% opacidad, cursor: not-allowed

6.5 Selects / Dropdowns

  • Trigger: Mismo estilo que inputs
  • Panel: --bg-surface, borde --bg-elevated, border-radius: 6px, sombra
  • Hover opción: rgba(245,110,15,0.06)
  • Seleccionado: Texto --accent + icono check
  • Z-index: --z-dropdown

6.6 Tooltips

  • Fondo: --bg-elevated, texto --text-primary, Oswald 12px
  • Border-radius: 4px, padding 6px 10px, flecha 6px
  • Delay: 300ms para mostrar, instantáneo para ocultar
  • Z-index: --z-tooltip

6.7 Modales

  • Fondo: --bg-surface, borde --bg-elevated, border-radius: 8px
  • Overlay: rgba(0,0,0,0.6) con backdrop-filter: blur(4px)
  • Padding: --space-6 (24px)
  • Animación: Scale desde 0.95 + fade, 200ms
  • Z-index: overlay --z-modal-overlay, contenido --z-modal

6.8 Toasts / Notificaciones

  • Librería: Sonner (integrado con shadcn/ui)
  • Posición: Arriba a la derecha
  • Estilo: --bg-surface, borde --bg-elevated, acento izquierdo de 3px en color semántico
  • Auto-dismiss: 5 segundos. Máximo 3 visibles, el más antiguo se descarta al llegar al 4to
  • Animación: Slide-in desde la derecha, 300ms
  • Z-index: --z-toast

6.9 Estados de Carga y Vacíos

  • Skeleton: Rectángulos pulsantes --bg-elevated sobre --bg-surface. Pulso: opacidad 0.4 → 1 → 0.4, 1.5s infinite.
  • Estado vacío: Icono Lucide centrado (48px, --text-muted), mensaje Oswald 16px, botón de acción opcional.
  • Loading inline: Spinner 16px usando --accent.

6.10 Iconos

  • Librería: Lucide Icons (incluido con shadcn/ui)
  • Tamaños: 14px (small), 16px (medium), 18px (large)
  • Stroke: 2px. Color hereda del texto padre.

8. Arquitectura Frontend (Enfoque Híbrido)

8.1 Grupos de Rutas (Next.js App Router)

app/ ├── middleware.ts ← Validación JWT + protección por rol ├── (auth)/login/ ← Login con video de fondo ├── (platform)/ ← Roles globales: Jefe, Coordinadores, Supervisor │ ├── layout.tsx ← Sidebar completa + header │ ├── dashboard/ │ ├── camiones/ │ ├── andenes/ │ ├── pallets/ │ └── reportes/ ├── (operativo)/ ← Planta: Pickinero, Cargador │ ├── layout.tsx ← Sidebar simplificada │ ├── picking/ │ ├── carga/ │ └── tunel/ └── (sag)/ ← Portal inspector SAG ├── layout.tsx ← Layout independiente └── exportaciones/

8.2 Protección de Rutas (middleware.ts)

  • Lee JWT desde cookie/header en cada request
  • Valida token y extrae el rol del usuario
  • Redirige usuarios no autenticados a (auth)/login
  • Redirige usuarios autenticados a su grupo de rutas según rol
Grupo de RutasRoles Permitidos
(platform)JEFE_DESPACHO, COORDINADOR, COORDINADOR_TRANSPORTE, SUPERVISOR
(operativo)PICKINERO, CARGADOR, OPERADOR_TUNEL, SUPERVISOR
(sag)SAG
Supervisor puede acceder tanto a (platform) como a (operativo). Redirige a (platform) por defecto.

8.3 Gestión de Estado en Tiempo Real

  • TanStack Query para estado del servidor (fetching, caché, refetching)
  • Socket.io client se conecta al montar el layout, se une a salas por rol (global, edificio, sag)
  • WebSocket → Invalidación de Query: Al recibir un evento, invalida la query key relevante para disparar un refetch con transición animada
  • Sin store global separado — TanStack Query sirve como caché de estado del servidor

8.4 Estrategia de Reconexión

  • Socket.io auto-reconnect con backoff exponencial
  • Al desconectar: toast sutil "Reconectando..." con acento --warning
  • Al reconectar: invalida todas las queries activas para sincronizar datos
  • Si desconectado >30s: banner persistente en la parte superior del layout

12. Comportamiento Responsive

BreakpointLayout
Desktop (>1024px)Sidebar completa expandida + contenido
Tablet (768-1024px)Sidebar colapsada por defecto, expandible con tap
Móvil (<768px)No es target principal. Sidebar se convierte en drawer off-canvas. Vistas Operativo son touch-optimized y funcionan bien en tablet/móvil. Vistas Platform degradan gracefully pero son desktop-first.

Las vistas Operativo están diseñadas tablet-first: targets de toque grandes (mínimo 44x44px), layouts simplificados, workflows compatibles con escáner.

13. Accesibilidad

  • Contraste: Todo el texto cumple WCAG AA (4.5:1 texto normal, 3:1 texto grande). --text-muted ajustado a #9A9A9A para cumplir 4.5:1 sobre --bg-surface.
  • Indicadores de foco: Todos los elementos interactivos muestran focus ring visible (glow --accent) al navegar con teclado.
  • Navegación por teclado: Todas las acciones accesibles vía Tab/Enter/Escape. Modales atrapan el foco. Items de sidebar navegables con flechas.
  • Lectores de pantalla: HTML semántico (nav, main, aside, table, button). ARIA labels en botones de solo icono y sidebar colapsada. Cambios de badges anunciados vía aria-live="polite".
  • Movimiento reducido: Respetar prefers-reduced-motion — desactivar animaciones Framer Motion, usar transiciones instantáneas.

14. Principios UX Clave

  1. Interactividad primero — Todo debe sentirse vivo y responsivo
  2. Complejidad apropiada al rol — Roles globales obtienen dashboards ricos; trabajadores de planta obtienen vistas de tarea enfocadas
  3. Feedback en tiempo real — Actualizaciones WebSocket reflejadas inmediatamente con transiciones visuales
  4. Estética industrial — Bordes definidos, separaciones claras, sensación de panel de control
  5. Claridad de datos — Sono monospace para datos asegura escaneo rápido de números y códigos
  6. Espaciado consistente — Sistema de espaciado base-4 + tamaños de botón siguiendo mejores prácticas UX
  7. Accesible por defecto — Cumplimiento WCAG AA, navegación por teclado, soporte lectores de pantalla
